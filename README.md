# 🚀 KEWA Software Development Portfolio

A modern, high-performance, and responsive portfolio web application built to showcase advanced digital solutions, AI integrations, and full-stack architecture. Crafted with precision under the **KEWA** brand by Deepak.

---

## ✨ Key Features

* **⚡ Modern UI/UX:** Sleek, futuristic dark-mode aesthetic built with clean CSS and custom styling.
* **🤖 AI & Full-Stack Capabilities:** Showcases expertise in AI Chatbots (Gemini integration), mobile apps, and robust backend systems.
* **☁️ Cloud Database Synced:** Real-time project management and dynamic updates powered by **Firebase Firestore**.
* **📩 Integrated Contact System:** Seamless client communication workflows backed by **Formspree** with custom success toast notifications.
* **📱 Fully Responsive:** Optimized seamlessly for mobile phones, tablets, and desktop displays with bottom navigation for mobile accessibility.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript (ES6+), Google Fonts, FontAwesome Icons
* **Backend & Cloud:** Firebase Firestore (Cloud Database)
* **Integrations:** Formspree API, Google Gemini API ecosystem
